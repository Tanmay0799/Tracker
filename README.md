# LifeOS V2
Glossy dark, mobile-first Life & Career Tracker.

Run locally from this folder:
python -m http.server 8000
Open http://localhost:8000

V2 includes daily tracking, study, job pipeline, three meals, health, weekly metrics, charts, insights, date switching, export and PWA support.

V2 is local-first. Production cloud login/sync is the next step.
